## Design

A base plate that acts as the foundation of the storage system. Boxes push onto it like Lego bricks — snap-fit sockets hold them in place without hardware.

### Key features

- **Push-fit sockets** — rounded square sockets with chamfered entry, boxes snap on securely but can be removed easily
- **Hex bowtie sockets** — hexagonal cutouts between the box sockets allow joining multiple base plates side-by-side using printed bowtie connectors
- **25mm grid** — all socket positions align to the system's 25mm grid unit

### Print settings

- Layer height: 0.2mm
- Wall thickness: 2mm (includes socket walls)
- No supports needed when printed flat
