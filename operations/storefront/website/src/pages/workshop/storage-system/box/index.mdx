## Design

The main storage container of the system. Features horizontal slots on both short inner walls at multiple height levels. Horizontal inlays snap into these slots using integrated flex tabs — enabling height-adjustable tool organization without permanent modifications.

### Key features

- **Wall slots** — horizontal slots on both short walls at regular height intervals, inlay flex-tab nubs click into these
- **Snap-fit base** — push-fit posts on the bottom mate with the base plate sockets
- **Height-adjustable organization** — place two inlays at different heights to cradle tapered tools (e.g., screwdriver handle at top, shaft at bottom)
- **25mm grid** — internal dimensions are a direct multiple of the grid unit

### How it works

For a screwdriver:
1. Place a horizontal inlay near the bottom of the box — set the dividers wide apart (shaft diameter)
2. Place a second inlay higher up — set dividers closer together (handle diameter)
3. The tool rests in both cradles, held securely at two points

### Print settings

- Layer height: 0.2mm
- Wall thickness: 2mm
- Print upright (box opening facing up) for best wall slot quality
