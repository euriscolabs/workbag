## Design

A printed bowtie connector that locks into the hex sockets between base plates, joining them into larger surfaces. Inspired by woodworking butterfly joints.

### Key features

- **Hex bowtie shape** — fits the hex sockets on the base plate, multiple orientation options
- **Snap-lock ridge** — a ridge on the bowtie side profile clicks into a valley in the socket, locking Z-axis movement so the connector doesn't slide out when the assembly is moved
- **Asymmetric key** — ensures grids align perfectly across joined plates
- **No hardware** — fully 3D printed, reversible connection

### Print settings

- Layer height: 0.2mm
- Ridge depth: 0.3-0.4mm
- Lead-in chamfer on ridge for smooth insertion
